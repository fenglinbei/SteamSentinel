# 0.3.0 后台消息与安装联合验收

更新：2026-09-21。实施中；用户已选择“同意新增可选结构化消息字段”，下述后台消息兼容扩展已冻结。

## 已冻结的兼容扩展

此前已冻结不向报告加入显示语言字段。本轮建议继续保持这一约定，同时为新后台结果加入可选的结构化消息字段，使 Worker/Broker 产生的结果和保存后的记录都能按界面或导出语言显示。

| 内容 | 建议 |
| --- | --- |
| 原始字段 | 原 `Title`、`Description`、`Message`、`Errors` 等继续保存来源原文，旧读取方式保持可用 |
| 新增字段 | 在对应记录增加可选的消息描述，记录稳定 `MessageId` 与有界参数；组合说明允许受限的子消息。不记录界面语言 |
| 示例 | 原 `Message: "文件已隔离"` 保留，另存消息 ID `remediation.file_quarantined`；英文显示从资源生成，不匹配中文原文 |
| 老记录和未知消息 | 缺描述或 ID 未识别时保留来源原文并标记；不推断状态、原因或处置资格 |
| 边界 | 限制 ID、参数数、字符数、组合深度和总文本预算；在 Worker/结果读取边界验证。显示消息不参与计划授权、目标身份或状态判断 |
| 验收 | 同一对象的双语导出 JSON 一致；稳定状态、原因、规则、哈希、动作和权限一致；旧记录可读；恶意/越界消息被拒绝或明确回退 |

该扩展使新 JSON 增加可选的消息结构字段，不能称为“相对上一开发版 JSON 完全没有新字段”。“不新增显示语言元数据”的约定继续有效。

## 已授权的后续工作

1. 盘点所有后台硬编码文字及其消费路径，区分产品说明、来源原文和检测匹配数据；逐项迁移，禁止把检测特征或规则条件当成译文。
2. 双语安装器沿用 AppId、安装位置、组件名称和升级链；补齐安装、卸载、自定义失败提示及快捷方式说明。
3. 将中文卫星资源纳入必需组件与完整性清单；核验缺失、修改、额外加载文件和升级后的资源一致性。
4. 修复干净安装时机器状态目录的权限前置条件，拒绝把已有不可信的非空状态通过改 ACL 变为可信；在隔离虚拟机验证安装、升级、卸载及数据保留。
5. 使用新构建运行完整源码回归、中英文真实界面和隔离实验验收。保留旧样本实验记录，当前构建分别记录实际通过项和环境/产品缺口。

Preview/RC 的发布范围和版本身份在候选实现、测试及证据齐备后另行沟通冻结。未完成的 AMSI 兼容性、Windows/DPI 或真实权限场景不会计为通过。

## 当前实现与证据

后台产品说明已接通结构化消息，包括发现项、执行结果、错误列表、复验观察、进度、范围/覆盖/内容来源、容器、关联组件、签名、信任/代理诊断、配置修复、病例与分批执行记录。程序生成的目标说明使用单独显示入口；操作路径和目标身份仍读取原始值。旧对象不序列化空描述；显示描述不进入类型化计划身份及配置证据指纹，UAC 前后的完整请求文件 SHA-256 绑定保持有效。

消息描述限制为 8 个参数、4 层、32 个节点、单参数 4,096 字符、总量 16,384 字符。参数保留为有界文本；数值按不变区域格式预先转成文本。报告、容器/诊断分片、Worker 进度与密码请求、受保护执行结果及病例读取边界验证新增描述；元数据计入原有传输/记录预算。原文字段经旧调用者覆盖后，已知且不再匹配的描述自动失效。索引和非法描述不会被静默过滤而绕过读取验证。超过生成预算时保留原文；未知或格式不符的 ID 显示原文，不推断动作状态。内部脱敏同时处理来源字符串与描述参数。
