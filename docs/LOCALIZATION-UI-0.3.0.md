## 已批准并实现的两项行为

2026-09-21，用户以“没问题，可以按这个冻结”批准以下规则。本轮已据此接入语言页、启动加载、管理员窗口继承及两处记录导出入口。

| 项目 | 已冻结规则 | 实现 |
| --- | --- | --- |
| 语言设置 | 自动 / 简体中文 / English；自动以 Windows 显示语言为准，中文使用简体资源，其余使用英文；按当前用户保存，下次启动生效，当前窗口与任务保持原状 | 启动在创建视图前解析设置；管理员窗口继承当前实际显示语言；保存成功与失败均有明确反馈 |
| 导出语言 | Markdown 和记录包说明默认跟随当前界面，允许本次另选中/英文；JSON 不增加显示语言字段，原始证据和旧自由文本保留并标注来源 | 普通报告与病例记录包均接入语言选择；JSON 跳过语言弹窗；导出选择不改变用户偏好 |

首次启动使用自动语言。设置文件损坏、过大或无法读取时保留原件，回退自动并提示；再次保存才会写入用户选择。当前语言通过进程显示默认值传给后台任务，不改变 Windows 或线程区域设置。

新管理员窗口仅允许传递白名单语言值、跨账户必须重新扫描，是既定安全约束。安装 AppId、目录、组件身份、AMSI 身份、隔离库位置和授权规则保持不变。此次没有引入新的发布或签名决定。
