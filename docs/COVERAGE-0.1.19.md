# 0.1.19 视觉协调修复

本版按最终反馈回归 0.1.18 的整体设计，视觉上调整表格密度、对齐、留白和按钮对比度，同版本继续修复结果摘要与补查提示文案。页签、输入框、展开控件及原有圆角不改造；不采用中途试验的新控件主题。扫描规则、处置计划及权限门禁沿用 0.1.18。后续按用户要求补充密码窗口的有序多密码、跳过全部和复用修复，见 [密码交互说明](PASSWORD-0.1.19.md)。

## 一致的呈现规则

本版本另包含文案缺陷修复，不升级版本号：未发现风险时，摘要根据本次检查完整性分别显示“已完成部分检查”“本次检查已完成”或“本次未执行检查”。快速检查留下缺口时提示完整内容扫描和额外检查选项；已做完整内容扫描仍有缺口时提示按具体原因补查。扫描结束不等于所有内容都完成检查，严重度也不等于已确认病毒。补查按钮明确为“补查所选内容”，不承诺能绕过权限、密码、格式或安全上限。所有检查与处置判断条件保持不变。

- 单行表格最小高度 32 DIP，单元格水平留白 8 DIP、垂直留白 3 DIP；真正由模板承接 Padding 与内容对齐，避免只有属性设置而没有实际效果。
- 严重度、分类、分数、记录数、日期和复选框居中；说明、标题、路径与状态文字左对齐。长文字换行时可适当增高，不用固定高度裁掉证据。
- 原有按钮 5 DIP、卡片 8 DIP、弹窗提示卡 6 DIP 圆角保持不变；页签使用 0.1.18 的系统模板，撤回造成右侧边线缺失的实验页签样式。系统文件选择器等原生窗口不改写。
- 可用次按钮保留原文字颜色，以轻微底色和较深边框加强对比；禁用按钮使用独立中性灰状态，不再整体半透明。主要动作保留原红色强调。改变颜色不改变 IsEnabled 或任何授权条件。
- 表格浏览不允许 Delete 键删除报告行；风险勾选仍由原有可选择条件约束。表格外框、选中颜色和全局字体沿用 0.1.18。

## 验证

`SteamSentinel.SelfTest.exe --layout-ui <新的输出目录>` 继续运行真实 WPF 测量、排列、模板与数据绑定测试，输出 PNG 和布局 JSON。除原有 92 条长路径压力用例外，还使用与用户截图类似的两条低风险信息、五组覆盖记录和隔离记录，检查实际行高、内容中心与留白、控件状态及键盘行为。

完整 SelfTest 包含上述回归，候选包的权威数量见 `SELFTEST-RESULTS.json`。每轮渲染与本机小规模测试结果应核对相同 BuildIdentity，不将旧截图或旧结果当成当前候选证据。

验证只使用无害合成记录，不执行真实隔离或恶意样本。客户区 DIP 测试不等于修改 Windows 缩放后的多显示器或辅助功能矩阵验收；沿用 0.1.18 的已测尺寸与边界。大量记录和超长内容仍可在列表/详情内局部滚动，不会为追求低行高而删除信息。
