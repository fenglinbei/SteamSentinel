# SteamSentinel 0.1.4 群内测试指南

## 测试前

1. 仅在无真实 Steam 资产、无重要文件或已做好备份的机器上做染毒测试。不要为了测试关闭现有安全软件。
2. 从群公告核对 `SteamSentinel-0.1.4-setup.exe` 的 SHA-256。安装器尚未签名，Windows 可能显示未知发布者。
3. 使用安装包完成安装。主界面应显示“受保护安装与组件完整性校验已通过”；如果显示便携/开发运行，隔离与恢复应保持禁用。
4. 不要把压缩包密码、Steam 登录凭据、支付信息或未脱敏报告发到群里。
5. 处置计划绑定发起扫描的 Windows 账户。标准账户通过 UAC 输入另一管理员账户凭据时会被安全拒绝，请切换到实际管理员账户重新扫描后处置。

## 最小验收顺序

1. **干净基线**：快速扫描、完整工坊扫描、单文件扫描各一次，确认窗口不冻结，覆盖状态与报告能正常导出。
2. **无害启发式项**：准备一个不会执行的测试文件，确认启发式发现默认不勾选，人工勾选后预览会显示“启发式”及 SHA-256，并出现 UAC 后的第二次确认。
3. **隔离与回滚**：确认原文件进入 `%PROGRAMDATA%\SteamSentinel\Quarantine`，随后回滚；如果原路径已重新出现，工具必须拒绝覆盖。
4. **Steam 恢复**：只在空白测试账号和可恢复环境中使用已知样本。处置 Steam 前端前完整退出 Steam，隔离后重新启动 Steam，让官方客户端补全缺失组件，再做一次完整复扫。
5. **永久删除**：确认未重启或没有完整干净复扫时按钮被阻止。测试结束后再决定是否删除隔离证据。
6. **卸载**：确认应用目录被移除，ArchiveWorker 的入站/出站防火墙规则被删除。隔离证据默认保留，需人工确认后处理。

## 反馈至少包含

- Windows 版本、是否管理员账户、Steam 安装盘和工坊库盘符。
- 工具版本、规则版本、主界面处置环境提示。
- 脱敏后的 Markdown 报告、失败动作的完整中文错误、复现步骤。
- 如果是卡死，记录发生在扫描、密码询问、UAC、隔离、回滚还是 Steam 重启后的哪一步。

不要上传正在运行的恶意样本，也不要要求其他测试者复现未知来源的可执行文件。
