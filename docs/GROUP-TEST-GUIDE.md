# SteamSentinel 0.1.8 群内测试指南

## 测试前

1. 仅在无真实 Steam 资产、无重要文件或已做好备份的机器上做染毒测试。不要为了测试关闭现有安全软件。
2. 从群公告核对 `SteamSentinel-0.1.8-setup.exe` 的 SHA-256。安装器尚未签名，Windows 可能显示未知发布者。
3. 退出旧版后使用安装包覆盖安装。主界面应显示“安装检查通过”，如果显示便携/开发运行，隔离、恢复及打开管理员窗口应保持禁用。
4. 不要把压缩包密码、Steam 登录凭据、支付信息或未脱敏报告发到群里。
5. 处置计划绑定发起扫描的 Windows 账户。标准账户应点击“打开管理员窗口”，在 Windows 中提供管理员凭据，再到新窗口重新扫描，确认原用户的 Steam 与工坊目录包含在扫描范围内。

## 最小验收顺序

1. **干净基线**：快速扫描、完整工坊扫描、单文件扫描各一次，确认窗口不冻结，覆盖状态与报告能正常导出。
2. **无害启发式项**：准备一个不会执行的测试文件，确认启发式发现默认不勾选，人工勾选后预览会显示“启发式”及 SHA-256，并出现 UAC 后的第二次确认。
3. **隔离与回滚**：确认原文件进入 `%PROGRAMDATA%\SteamSentinel\Quarantine`，随后回滚，如果原路径已重新出现，工具必须拒绝覆盖。
4. **Steam 恢复**：只在空白测试账号和可恢复环境中使用已知样本。处置 Steam 前端前完整退出 Steam，隔离后重新启动 Steam，让官方客户端补全缺失组件，再做一次完整复扫。
5. **永久删除**：确认未重启或没有完整干净复扫时按钮被阻止。测试结束后再决定是否删除隔离证据。
6. **卸载**：确认应用目录被移除，ArchiveWorker 的入站/出站防火墙规则被删除。隔离证据默认保留，需人工确认后处理。

## 权限与提权重点核对

1. 用普通权限启动安装版，确认 Users 只有“读取和执行”时显示安装检查通过。不要手动授予写入权限。
2. 在具有拆分令牌的管理员账户中，确认处置预览后可以自动请求 UAC，不需要先手动重开应用。
3. 点击“打开管理员窗口”，第一次取消 UAC，原报告、勾选和窗口应保留。第二次同意，新窗口应显示管理员状态且要求重新扫描，不能自动执行旧计划。
4. 使用标准账户，在 UAC 中输入另一管理员账户凭据，新窗口重新扫描并确认范围后才能处置。没有凭据时仍可扫描和导出报告，不应声称已获得授权。
5. 修复安装后点击“重新检查”，按钮状态应更新，已有报告和选择不应被清空。真正可写或缺失组件的安装仍应禁用处置及提权入口。
6. 新旧窗口不要同时执行处置，管理员窗口仍须核对预览并二次确认，压缩包读取仍在受限 Worker 内完成。
7. 便携 ZIP 仅扫描，不能用提权按钮绕过安装要求。主界面仅显示版本号 0.1.8。

## 0.1.8 启动修复重点核对

1. 退出旧版普通窗口和管理员窗口，用安装包覆盖升级，确认两个入口均运行 0.1.8，不要混用旧 DLL。
2. 普通窗口快速扫描一次，再点击“打开管理员窗口”，在新窗口快速扫描。两种权限下都应正常启动内容扫描，不再出现本次已定位的 `0xc0000142`。
3. 用无害加密 ZIP 检查管理员窗口的密码往返、跨文件复用、取消与再次扫描，测试不需要执行样本。
4. 若仍失败，关闭系统错误框后导出报告，提供阶段、退出码、Windows 版本与当前权限。不要通过关闭防护、放宽目录写权限或替换单个 EXE 排查。
5. 内容检查失败时，已完成的系统检查仍保留，顶部必须提示扫描不完整或已有威胁，不能显示完整干净复扫。该状态不能解锁永久删除。

## 密码与扫描兼容性复测

1. 扫描本地提供的样本文件，不需要启动样本。密码先选“当前外层文件及嵌套包”，扫描多个同密码外层包时可选“本次扫描所有压缩包”，不应再只按相同哈希复用。
2. 让密码输错一次再更正，或跳过内层包，检查结果没有重复，且未解开的层仍有覆盖说明。
3. 核对命中成员位置与外层隔离目标，压缩包中多条命中只应隔离外层一次。修改外层文件后执行旧扫描的处置，应要求重新扫描。
4. 反编译源码和高置信启发式项目不应默认勾选，已确认恶意项可预选，正常依赖、音效素材、纯分析文档不应被一概标红。
5. 如果安全中心处理了样本或工具组件，先查看具体路径，不要盲目“全部保留”、恢复或关闭防护，确认是原件还是临时解包副本。
6. 将密码窗口缩小，或在 150%/200% 缩放下检查长路径，仍应能滚动输入与选择复用范围，底部的继续/跳过按钮不能被遮住。
7. 主界面不出现 GROUP PREVIEW、REVIEW 或版本副标题。
8. 勾选“本次扫描遇到的所有压缩包”后，下一次需要输入密码时该选项仍应选中。已经缓存的密码不因普通大文件被跳过而失效，未验证的密码不会直接复用。
9. 出现“已保存的密码未能解开这一层”时，可输入不同的内层密码或跳过。重复输入同一失败密码不会重复解包，每份内容最多接受三次输入，达到上限或跳过后，相同内容在别处出现不再打断。
10. 扫描结束后点击“重试未解密内容”，确认只重新检查相关外层文件，旧密码已清空。若有重要的旧扫描报告，请先导出，重试结果不代表全机扫描。
11. 用无害 ZIP AES、传统加密 ZIP、RAR 和 7z 分别测试输错再更正。损坏包应出现在覆盖说明里，后面的文件仍应完成扫描，不再出现整次扫描失败的未知格式弹窗。

## 反馈至少包含

- Windows 版本、是否管理员账户、Steam 安装盘和工坊库盘符。
- 工具版本、规则版本、主界面处置环境提示。
- 脱敏后的 Markdown 报告、失败动作的完整中文错误、复现步骤。
- 如果是卡死，记录发生在扫描、密码询问、UAC、隔离、回滚还是 Steam 重启后的哪一步。

不要上传正在运行的恶意样本，也不要要求其他测试者复现未知来源的可执行文件。
