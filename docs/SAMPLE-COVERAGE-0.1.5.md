- 两份 MSI 的安装数据库已在本地只读分析，发现异常打包/脚本启动链，产品内按精确哈希提供“可疑、可手动隔离”，并明确内部未展开。尚未证明其最终完整行为，不能标为已确认假红信。
- 反编译/反混淆副本与实际投放载荷分开，副本只提供人工确认后的隔离。

## 静态依据

- payload.bin（SHA-256 `4FB2B5E6…F91E926C`）使用同包密钥数据静态解密、解压，输出仍仅作为字节数据检查，没有加载执行字节码，发现 Steam 内存凭据读取、DPAPI 解密、家族密钥和外传端点。
- DesktopNotify / locale_patch / SteamCFyinxiao 包含客服路由替换、账户提醒强制显示与 steamui 写入相关特征，鸭科夫的音效素材、通用依赖未加入恶意规则。
- steamprocess 插件的前后端包含伪造账户状态、拦截登录、验证资料发送队列和第三方接收端点，Millennium 及其正常运行库不因此判毒。
- upupoo-installer 的精确成员哈希曾被本机 Defender 检测为 Ransom:Win32/Filecoder!MSR，规则保留这一证据来源，不泛指同名正常软件。
- 其余已复核但证据不足以确认恶意的对象维持可疑状态，规则中的 `Evidence` 给出依据与限制。

完整原始样本和展开后的恶意字节不进入 Git 或发布包，公开源码仅保留规则、哈希、上述元数据及无害测试。

## 仍需人工验收

在已有隔离云电脑上，使用安装版确认“扫描 → 选择 → 动作预览 → UAC → 隔离 → 复扫 → 回滚”的完整交互，并检查较高 DPI 下的密码窗口。当前本地回归验证了扫描、计划生成、目标身份校验及底层句柄复制/删除，不等同于已完成本版本的安装态 UAC 端到端测试。未完成代码签名、外部安全审计与完整操作系统矩阵测试。
