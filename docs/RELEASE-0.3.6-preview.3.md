# SteamSentinel 0.3.6 — 守护链清理与处置复验修正

发行标识 `v0.3.6-preview.3`，规则版本 `2026.11.17.1`。本包整合 PowerShell watchdog、临时 CMD 更新链清理与结果页升级，并修正静态样本隔离时发现的防火墙复验超时和错误原因展示问题。

## 本次修正

- 程序防火墙规则的只读复验改用固定规则名称筛选，再严格核对精确名称及全部应用、方向、阻断动作、端口、地址、服务、接口与配置文件条件。该动作的单次等待上限为 15 秒；其他动作仍为 4 秒，第二轮整体预算仍为 20 秒。病例跨会话复验使用相同的专用上限。超时、取消、读取失败或状态不符仍会阻止依赖动作执行。
- 处置汇总保留导致跳过的首次执行或复验原因。完整记录可查看和复制所选目标、相关前置动作、两轮复验及运行级错误；后一次状态不能掩盖已经发生的失败。
- 所选目录因不安全路径而全部跳过时，明确显示“所选路径未执行内容检查”，并引导查看未检查原因。仍拒绝目录联接和其他重解析跳转；可选择实际物理目录重新扫描。
- 快捷方式回归使用固定的网络 LinkInfo 夹具，使本机与 Windows CI 的测试数量一致，同时保留真实 Windows IDList 的检查。

## 守护链与结果页

检测覆盖已核验的新主程序、内嵌 Core、watchdog、更新器和启动器，包含有／无 UTF-8 BOM 的脚本资源与更新副本。已确认的安装范围可关联 `%ProgramData%\SteamAlertUpdater`、驻留目录的 `Updater`、固定缓存及 `.new.exe`、`.old`、`.bak` 文件。下载目录中的样本不会单独授权处理本机安装项。

清理依次停止预览中精确绑定的 watchdog、子脚本和 CMD 实例，移除绑定自启动，停止驻留程序，再隔离脚本及确认的主程序、更新副本。每一步都复查字节、命令、PID、创建时间和相关状态；新实例、未知替换或无法确认的状态会停止后续动作。系统 PowerShell／CMD 本身不被隔离，无关正常脚本不被终止。

结果页分别统计重点项与参考信息，单纯格式差异默认折叠，分数显示在详情中；全选重点项不会选择折叠参考项。保守／激进模式、Steam 脚本及配置修复继续保留。

## 升级与验证范围

退出主程序和管理员窗口后安装完整包，不要混用不同构建的 EXE／DLL。升级后重新扫描原范围，再预览新的处置计划；保存的旧计划不会重放。失败记录中防火墙动作执行成功不代表其生效条件已经通过复验，文件显示“跳过”也不表示已经隔离。

最终构建身份、完整回归及专项结果见发行附件 `RELEASE-METADATA.json`、`SELFTEST-RESULTS.json`、`WATCHDOG-RESULTS.json`、`FINDING-PRIORITY-UI-RESULTS.json` 和 SHA-256 清单。测试使用无害夹具与离线样本字节，未运行恶意样本或连接样本服务器。另一台报告机器上的修正后复测、真实感染清除、重启及十五分钟更新周期验收仍需分别验证。

本包是自签名 Preview，不具备公共受信任证书链，不导入证书或修改系统信任设置。旧 `preview.1` 与 `preview.2` 标签对应较早的测试构建；公开发行使用本次 `preview.3` 标签和独立附件。
