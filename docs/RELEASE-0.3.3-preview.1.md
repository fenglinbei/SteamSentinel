# SteamSentinel 0.3.3 深空当铺 SteamAlert Mod 检测

2026-11-10 · [English](RELEASE-0.3.3-preview.1.en.md)

版本 **0.3.3** 使用规则 `2026.11.10.1`，以 `v0.3.3-preview.1` 发布。退出主程序和管理员窗口后运行完整安装包，再重新扫描。安装包使用 `CN=fenglinbei` 自签名，Windows 可能提示发布者不受信任。[下载与校验附件](https://github.com/fenglinbei/SteamSentinel/releases/tag/v0.3.3-preview.1)

## 扫描与处置

1. 安装过相关 Mod 的用户可先运行完整扫描。检查工坊或游戏 Mod 根目录中的 `3835179592\PWLoader.dll`、`3835252991\PWLoader.dll`，以及 `%LOCALAPPDATA%\SteamAlertDemo` 下的常驻程序。仅收到压缩包时，可直接选择“扫描文件/目录”检查原包。
2. 精确 SHA-256 命中区分下载器、常驻宿主和核心 DLL。发现已安装的下载器或常驻宿主后，工具会检查对应位置的另一组件。核对预览中的每个文件，以及有文件证据的进程或自启动项，再确认处理。压缩包内成员的路径用于定位原包内容。
3. 新的行为检查可识别 Mod 初始化代码下载并启动同一可执行文件、宿主从资源加载核心、核心通过 Steam 调试接口进行持久化等组合。仅有行为证据时，结果供人工复核。
4. Steam 界面脚本也可能由合法扩展修改。扫描会记录脚本加载的本地地址和文件哈希。命中特定家族地址时，工具会核验当前用户的已知常驻宿主以解释关联。先处理已确认的再感染来源，再使用 Steam 官方安装器修复非预期的客户端修改并复扫。

## 离线验证

原始 RAR 的 30 个文件成员全部完成哈希检查。两个 `PWLoader.dll` 副本和一个常驻宿主分别命中精确规则，并各有一条行为结果。宿主内嵌的 `SteamAlertCore.dll` 另行提取校验，命中核心规则。DailyCheckin 和 SpeedUp 两个正常 DLL 对照均未触发这组家族规则。此验证采用静态读取，覆盖所测样本与对照。

开发阶段的 SteamAlert 专项回归通过 51 项，共享误报回归通过 164 项，两套均零失败、零跳过。全量自测、构建来源和最终附件哈希见发行页的验收摘要、发布身份及 SHA-256 清单。感染主机的处置与重启恢复效果仍需实机验证。
