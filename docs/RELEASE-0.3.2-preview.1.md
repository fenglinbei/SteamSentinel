# SteamSentinel 0.3.2 精确文件范围与确认

2026-11-10。[English](RELEASE-0.3.2-preview.1.en.md)

本轮产品版本为 **0.3.2**，发布标签为 `v0.3.2-preview.1`，规则版本仍为 `2026.09.28.1`。继续使用 `CN=fenglinbei` 自签名 Pre-release 渠道，保留现有 stable/latest 指向。请从[本轮发行页](https://github.com/fenglinbei/SteamSentinel/releases/tag/v0.3.2-preview.1)取得完整安装包，退出普通及管理员窗口后升级，再重新扫描需要处理的范围。

## 文件范围与使用方式

- 符合现有证据和处置资格要求的精确文件，可以从任意普通本地目录进入预览，包括 Windows 或 Program Files 中经核验未受保护的普通文件。路径不在原有自动范围内，不再单独导致文件无法选择；这不扩大恶意判定规则，也不将弱证据升级为可处置证据。
- 结果列表提前显示“待确认”“敏感位置 · 需核验”或“已阻断”，分别统计可准备、待确认、需核验和阻断项目。待确认与需核验项目默认不勾选，可手选或通过“全选”纳入预览；阻断项目不能选择。
- 预览保留每批完整动作清单、精确目标及未纳入原因。范围说明和敏感位置的影响并入原有确认区域；Windows 或应用目录中的文件即使未受系统保护，隔离后也可能影响系统或应用运行。
- **新增独立范围授权弹窗为 0**。原有应用预览和每批管理员最终确认继续保留，普通分批确认次数不因范围授权增加。Windows 的 UAC 提示仍按账户、提权状态和执行流程出现，不能将此描述为整个任务只需一次确认或一次 UAC。
- 确认只适用于本次计划列出的精确文件和其他明确列出的动作，不授权整个目录、相邻文件、以后扫描或另一份计划。管理员执行端独立核对计划、内容哈希、文件及父目录身份；界面选择或计划中的请求标记本身不构成授权。

通用词语共现、退役弱规则和证据不足的发现仍只供复核。目录隔离、进程、服务、注册表、任务和配置动作继续使用各自原有资格与依赖条件；本轮没有增加递归目录处置权限。

## 仍会阻断的情况

Windows 资源保护（WRP）文件、系统关键路径、工具自身程序和状态目录保持保护。UNC 网络路径、设备路径、重解析点及路径重定向不在此次普通本地文件授权范围内。文件有多个硬链接，或内容、文件身份、父目录身份在核验后变化时，相关操作会被拒绝。

扩展范围隔离必须能保存和核验恢复所需的原始安全信息、属性及时间。额外数据流、加密、压缩、稀疏等当前不能完整恢复的特殊元数据会阻断处置；不能读取或验证必要恢复信息时也会停止。确认不能绕过文件权限、系统保护或这些恢复条件。阻断原因和未完成结果会保留，不能将其记作成功。

本轮未实现自动系统修复或离线处置队列。仍需通过 Windows 或软件官方提供的方式修复已损坏的系统和应用组件。

## 恢复与旧数据

恢复扩展范围文件时，需要再次确认。管理员执行端只采用受保护隔离目录中经核验的可信清单，检查隔离副本哈希、原目标及父目录身份和保存的恢复信息；不会根据普通报告中的路径授予恢复权限。目标已存在时拒绝覆盖；信息不足、身份改变或核验失败时保留隔离副本。恢复支持的文件会同时恢复记录中的权限、属性及创建和修改时间。

旧报告、旧病例和旧计划保持兼容，但升级不会自动授予新的范围权限，也不会重放保存的计划。请重新扫描并确认新计划；历史风险、未完成和未知结果不会被改写为安全或成功。

0.3.1 的诊断计数、批准预算同步和大病例分片保存修复继续保留。0.3.0 不能读取新保存的分片病例；回退前导出完整记录包，并保留整个病例目录。详见[0.3.1 数据兼容说明](RELEASE-0.3.1-preview.1.md)。统一启动器、受限工作进程和既有处置恢复机制继续保留。

## 回归与发行核验

最终发布附件 `SCOPE-AUTHORIZATION-RESULTS.json` 用于核对精确范围授权、敏感位置、阻断、确认取消、身份变化、隔离恢复、旧数据兼容和双语界面等专项结果；`LARGE-SCAN-RESULTS.json` 用于核对最终工作进程的大规模无害文件实扫，以及同一报告的病例保存、重读、更新和导出。实际覆盖、通过数、失败数、跳过项和二进制身份以附件为准，本文不预填尚未执行的结果。

精确源码提交、源码树、构建身份、签名和附件哈希以 `PUBLICATION-IDENTITY.json`、`RELEASE-METADATA.json`、`ACCEPTANCE-SUMMARY.json` 和版本前缀 `RELEASE-SHA256.txt` 为准。完整自测、统一启动、Worker 防火墙契约、安装维护和状态迁移各自提供结果；不同专项的计数不相加冒充一次完整回归，也不沿用旧版本结果作为本轮通过证明。

无害夹具和大规模实扫不等于真实感染清除、重启恢复或所有 Windows 环境的安装验收。旧 CET 硬件、Windows 10/11 安装界面、物理跨屏和外部安全审计是否复测，应按本轮验收附件中的明确记录判断。自签名包没有公共受信任证书链或时间戳，Windows 仍可能提示发布者不受信任；安装包不会自动更改系统证书信任。此前启动兼容边界见[0.3.0 修订 5](RELEASE-0.3.0-preview.5.md)。
