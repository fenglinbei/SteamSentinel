# 0.1.18 UI 布局修复与验证边界

本版修复顶部过高、风险表列宽坍缩，以及整页双向滚动导致主要控件不可见的问题。扫描和处置逻辑沿用 0.1.17。

## 使用变化

- 主页面不再整页横向或纵向滚动；扫描、导出与当前结果页操作固定可见。
- 普通窗口显示完整的产品顶栏，小窗口收紧顶栏和间距，默认折叠可选详情；扫描选项与证据详情互斥展开，避免同时占满结果区。
- 风险表六列保持可读宽度。长标题和路径显示摘要，悬停或展开“所选项详情”阅读全文；大量记录仅在列表内部纵向浏览。
- “未检查内容”页底部显示补查按钮，“处置结果”页底部显示完整复查说明入口，不再混入当前页无关的处置按钮。
- 预览表保留动作顺序和批次，移除 WPF 视觉分组引起的列宽收缩；选择行查看完整目标和核对依据，完整计划说明在独立页签中。确认与执行区固定在底部。
- 密码窗口的输入、三种复用范围以及继续/跳过按钮默认可见，完整路径和补充说明局部展开；不改变复用范围默认值或密码存储行为。
- 极短窗口进行操作时，活动状态栏临时替代品牌顶栏；操作结束恢复顶栏。表格使用像素滚动，超长单行末尾也能到达。
- 空覆盖页清除上一页详情；长复查结果与文件占用信息使用可滚动、可复制的只读窗口，关闭按钮固定可见。

## 自动验证

`SteamSentinel.SelfTest.exe --layout-ui <新的输出目录>` 运行真实 WPF 模板、数据绑定、测量和布局，并生成 PNG、每张布局指标 JSON 与 `layout-test-results.json`。同一组断言也纳入完整 SelfTest。

主窗口客户区覆盖 1148×780、1024×650、900×580、800×500、784×460 DIP，使用 92 条无害合成记录；检查空表显示后动态填充、滚动选择后列宽、首条完整摘要、按钮边界/重叠、展开证据/选项、扫描活动、三个结果页、隔离页以及同一窗口大小往返变化。弹窗覆盖 760×520、600×420、440×360 的预览客户区及 596×554、420×340 的密码客户区。

权威通过数量以该候选包的 `SELFTEST-RESULTS.json` 为准，截图和布局指标以对应 BuildIdentity 的独立布局输出为准。合成界面中的威胁数量不代表本机实际检测结果。

## 未代替的验证

- 客户区 DIP 回归不是修改 Windows 缩放比例后的真实多显示器 DPI 验收，也不替代屏幕阅读器、高对比度和所有字体设置验证。
- 超出已测最小有效工作区时不保证全部关键控件无滚动。正常大量列表、超长证据与帮助说明仍需局部纵向浏览。
- 本轮不执行恶意样本，不安装/覆盖现有程序，不变更防火墙或隔离数据，不做真实提权处置。
- 包仍是未签名的受控预览版本；公开发布、安装升级和安全边界要求继续适用。
