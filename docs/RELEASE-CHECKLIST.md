# 0.1.8 群内受控发布与公开发布检查清单

## 本版已完成

- [x] 普通权限只读扫描与管理员权限处置分离。
- [x] Steam 多库与 Wallpaper Engine 工坊发现。
- [x] 真实格式、MP4 覆盖物、递归压缩包和加密密码交互。
- [x] 扫描覆盖状态和不可判定状态不冒充“安全”。
- [x] 处置预览、精确哈希复核、隔离清单、回滚和永久删除。
- [x] 165 项本地自动回归和 WPF 离屏布局检查，样本库静态回归沿用 0.1.6 证据，安装态 UI 与真实 DPI 验收仍列在下方。
- [x] 真实 High 管理员父进程启动 Low Worker，安全握手与无害文本/ZIP 扫描通过，未修改既有安装或调用方权限。
- [x] RX 权限误判修复、既有安装目录只读验证、取消与失败的提权模拟、标准账户新窗口引导及刷新状态保留报告。
- [x] Low Integrity 受限令牌、先入 Job 再执行的 Worker 启动顺序、精简环境变量与安全握手。
- [x] Program Files 安装器、运行时 ACL/组件哈希门禁，以及 Worker 精确路径双向防火墙阻断。
- [x] Broker 计划哈希/SID 绑定、固定结果目录、句柄绑定文件隔离、目录指纹、注册表值与任务哈希复核。
- [x] 自包含 win-x64 便携扫描包、安装包、源码包、发布 SHA-256 和第三方声明。

## 群内受控发布前必须完成

- [ ] 在一台未安装旧版的 Windows 11 x64 机器上走完安装、普通权限启动、快速扫描、完整扫描与卸载。
- [ ] 在已感染的空白测试机上完成一次“扫描 → 预览 → UAC 二次确认 → 隔离 → Steam 官方组件补全 → 复扫”。
- [ ] 用无害文件验证启发式项默认不选、手动选择后可隔离、回滚不覆盖现有文件、永久删除仍受重启与干净复扫门槛限制。
- [ ] 核对发布哈希文件，通过群公告固定安装包 SHA-256、版本号、已知限制与误报反馈入口。
- [ ] 0.1.8 仅群内受控发布，不承诺无毒，不诱导关闭杀毒软件，不在群外镜像扩散。
- [ ] 安装后测试 UAC 取消与同意、标准用户输入另一账户凭据后重新扫描、管理员窗口中的 Worker 握手与处置闭环。

## 正式公开分发阻断项

- [ ] 为 `SteamSentinel.exe`、`SteamSentinel.ArchiveWorker.exe`、`SteamSentinel.Broker.exe` 申请并执行 Authenticode 签名；发布页固定公钥/证书信息。
- [x] 使用安装器写入管理员保护目录并设置 ACL，普通用户不能替换 Broker 或 Worker；便携运行不开放管理员处置。
- [x] ArchiveWorker 使用 Low Integrity 受限令牌、Job Object 与精确路径网络阻断。
- [ ] 进一步迁移到 AppContainer 或等价的最小文件授权模型，阻止读取本次扫描范围以外的用户文件。
- [ ] 对 SharpCompress 输入面和自研 MP4/路径解析器执行持续模糊测试。
- [ ] 完成独立安全代码审计，重点审查 Broker 的 TOCTOU、重解析点、ACL、跨卷回滚和计划真实性。
- [ ] 设计签名规则更新、版本回退保护、撤回和离线更新流程。
- [x] 采用 Apache License 2.0，添加标准 `LICENSE`、`NOTICE` 与发行包复制逻辑。
- [ ] 决定贡献者协议或开发者原创声明，并制定项目名称与图标的商标使用政策。
- [ ] 在干净的 Windows 10/11 x64、100%–200% DPI、标准用户/UAC、Defender 开启状态下做矩阵测试。
- [ ] 扩充安装/卸载、崩溃恢复、辅助功能、隐私声明和误报申诉流程。
- [ ] 建立可复现构建或至少双人独立构建与哈希比对流程。

## 审查者建议重点

- 对照 `docs/THREAT-MODEL.md` 检查每一条信任边界是否在代码中二次校验。
- 尝试使用过期计划、改动后的文件、路径穿越、重解析点、重复事件 GUID 和占用中的回滚目标。
- 检查所有 `Partial` 分支是否在 UI 与导出报告中保持不可误解。
- 在正式签名之前，不要把本候选包上传到公众下载页。
