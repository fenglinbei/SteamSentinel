## 采集范围

代理固定读取 8 个本地来源：当前用户及本机 Internet Settings，用户及本机 Internet Settings 策略，用户及本机 Internet Explorer Control Panel 策略，WinHTTP 默认配置，以及当前用户 WinINet 已保存连接配置。用户注册表通过目标 SID 显式读取；当前用户 API 受有效用户 SID 核验约束。保留来源位置、类型、读取状态、代理服务器、PAC 地址、绕过列表和自动检测信息。某字段不可读时不丢弃其他字段中的有效线索。

证书只读枚举 `CERT_STORE_PROV_SYSTEM_REGISTRY_W` 提供的 CurrentUser／LocalMachine × Root／CA 四个物理注册表来源，避免将用户逻辑库中继承的机器证书误记为用户自行安装。保留公开 DER、DER SHA-256、SHA-1 指纹、来源 ID、主体／颁发者、有效期、CA 约束、KeyUsage 和 EKU。不读取私钥，不导入证书。

离线链使用采集快照中的 Root 锚点和 CA 中间证书，关闭证书下载与撤销联网检查。若 Windows 链引擎返回快照外证书，结论记为未检查；链未通过不能据此判恶。主体与颁发者编码相同单独记录，`SelfSignatureVerified` 保持未知，证书有效期不当作安装时间。

关联只表达真实来源、离线链 DER 对应和相同 DER，不推断代理写入者或证书使用者。`mitmproxy`、Steam 站点证书名称是用途复核提示，不是恶意判定；合法代理、开发证书和同机出现均不能授权修改。

## 完整性、资源和导出

每个来源和检查都有独立状态：已读取、来源不存在、未检查、权限不足、失败、达到上限或取消。必要检查未完成时标记 Partial；PAC 正文、网站 TLS、安装时间和写入者属于本批明确未开展的范围，不伪装已验证。

默认每存储最多 2048 张证书，每张 DER 最多 128 KiB，总 DER 最多 16 MiB；每个代理值最多 8192 字符，每类采集器使用 20 秒协作时间预算。同步 Windows API 在调用前后检查时间和取消，无法承诺在单个原生调用内部立即停止。关联最多 16384 条，达到上限保留原始观察并显示未完成。

JSON 报告包含来源、关系、状态与公开 DER，Markdown 提供可读解释。已识别的代理凭据字段在进入报告前隐藏，原值以摘要保留；报告仍可能包含用户名、机器名、路径和配置地址，导出由用户主动触发，不上传。处置证据 ZIP 将最新诊断独立保存为 `trust-proxy-diagnostics.json`，不重写处置前的 `scan.json`，不附带样本。

工作进程协议按独立诊断分片传递这些记录，每条消息小于 1 MiB；证书在传输时使用 Base64Url，接收后恢复原 DER 并复核摘要。分片序号、来源 ID、SID、累计数量和字节预算全部通过核验后才提交；分片未齐时保留 Partial，不接受完成声明。系统阶段取消或失败也会保留已读取的检查点，并说明内容检查尚未开始。

## 本批边界

本批没有实现代理／证书修复动作、未知 DLL 家族判定、MSI CustomAction 完整语义、写入进程定位或跨重启清除验证。没有执行三个已解密 MSI，也没有以其文件名新增恶意规则。当前只读诊断不能宣称已覆盖或清除该变体。

证书来源不覆盖组策略／企业／AuthRoot／其他用户及其他物理提供程序；代理也不覆盖所有程序的会话覆盖设置。该结果是本机配置与证书快照，不能代表 Steam 实际采用的代理或站点 TLS 链。
